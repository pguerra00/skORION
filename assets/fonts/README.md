The desktop Studio theme bundles these fonts so it works without a network connection:

- [Marcellus](https://github.com/google/fonts/tree/main/ofl/marcellus), regular.
- [Josefin Sans](https://github.com/google/fonts/tree/main/ofl/josefinsans), variable weight.

Downloaded from the official Google Fonts repository. Their original SIL Open
Font License texts and copyright notices are included alongside the fonts.
The GUI falls back to installed fonts if the bundled assets are unavailable.
